Док где удобно

Внизу по центру, слева или справа. Полупрозрачный, поверх окон и над панелью задач. Может прятаться и выезжать у края экрана.

📌

Закрепление

Перетащите на док программу, ярлык или папку. Порядок меняется мышью, вынесли значок за док — он открепился.

🔍

Увеличение

Значки под курсором плавно растут, соседние — чуть меньше. Значки в высоком разрешении, без размытия.

🪟

Запущенные программы

Точка под запущенной программой, синяя — у активной. Щелчок — переключиться или свернуть, средняя кнопка — новое окно.

📋

Меню окон

Правый щелчок по значку: список окон программы, «Открыть расположение файла», «Открепить» и «Закрыть».

🗑️

Корзина

Видно, пустая она или нет. Бросьте файл на корзину — он удалится в неё; «Очистить корзину» — в меню.

🫥

Без панели задач

Панель задач Windows можно спрятать. Она вернётся при выходе из DockDesk — даже после аварийного закрытия.

🎮

Не мешает играм

Над полноэкранными играми и видео док уходит с экрана сам.

🪶

Лёгкий

Без движения мыши DockDesk не тратит процессор: кадры рисуются только во время анимации. Светлая и тёмная тема.

Как установить

  1. Скачайте DockDesk-win64.zip.
  2. Распакуйте в постоянную папку, например Документы\DockDesk.
  3. Запустите DockDesk.exe — внизу экрана появится док, у часов — значок с настройками.
  4. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

Вопросы

Почему SmartScreen предупреждает?

Программа новая и пока не подписана платным сертификатом. Скачивайте DockDesk только со страницы выпусков на GitHub — рядом с архивом лежит файл .sha256 с контрольной суммой.

Я спрятал панель задач. Как её вернуть?

Выключите «Скрывать панель задач Windows» в настройках или выйдите из DockDesk через значок у часов. Если программа закрылась аварийно, панель вернётся при следующем запуске.

Не будет ли тормозить компьютер?

Нет. Пока вы не наводите мышь на док, DockDesk ничего не рисует и не опрашивает: за окнами он следит по событиям Windows.

Программа что-нибудь отправляет?

Нет. В интернет DockDesk обращается лишь к GitHub за обновлениями — это можно выключить. На этом сайте нет счётчиков и аналитики.
