## 👀 DockDesk для Windows 1.0.2

**Скачать:** `DockDesk-1.0.2-win64.zip` ниже (или постоянная ссылка `DockDesk-win64.zip`). Распакуйте и запустите `DockDesk.exe`.

### Что нового
- Когда панель задач Windows спрятана, на доке появляются часы и дата, громкость, сеть, уведомления, параметры Windows, кнопка «Пуск» и значки в трее (Discord, Steam и сам DockDesk). Щелчок по часам открывает календарь
- По умолчанию панель задач скрывается, окна занимают весь экран, а док остаётся поверх них. По желанию можно оставить место под док или включить автоскрытие
- Если у программы несколько окон, щелчок по значку показывает список с заголовками (и миниатюрами, если Windows их даёт). В меню правой кнопки — «Новое окно», «Закрепить» / «Открепить» и «Закрыть все»
- Закреплённые программы с панели задач Windows можно перенести на док: при первом запуске или кнопкой «Импортировать закреплённые с панели задач» в настройках. Проводник остаётся закреплённым, повторы пропускаются
- Кнопка «Показать рабочий стол», горячие клавиши Win+1…9 и 0, стопки для закреплённых папок и число файлов в корзине. Каждую возможность можно выключить
- Док можно поставить на основной экран, на экран под курсором или на выбранный монитор

### Исправлено
- При аппаратном ускорении док иногда пропадал. Если видеокарта не справилась, DockDesk сам переключается на обычную отрисовку и пишет причину в журнал `%APPDATA%\DockDesk\DockDesk.log`
- Иногда док прятался за рабочий стол и возвращался, только если щёлкнуть по пустому месту. Теперь он остаётся поверх окон, а рабочий стол больше не принимается за полноэкранную программу
- Развёрнутые окна больше не оставляют пустую полосу там, где была панель задач. Если DockDesk закрылся аварийно, рабочая область восстанавливается при следующем запуске

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
