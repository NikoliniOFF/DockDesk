## 👀 DockDesk для Windows 1.0.0

**Скачать:** `DockDesk-1.0.0-win64.zip` ниже (или постоянная ссылка `DockDesk-win64.zip`). Распакуйте и запустите `DockDesk.exe`.

Первая версия — док внизу экрана, как в macOS.

### Что нового
- Док внизу, слева или справа: полупрозрачный, поверх окон, с автоскрытием
- Закрепление программ, ярлыков и папок перетаскиванием; порядок меняется мышью
- Плавное увеличение значков под курсором, подписи и подпрыгивание при запуске
- Запущенные программы с точкой; щелчок — переключиться или свернуть, средняя кнопка — новое окно
- Корзина на доке: показывает, пустая она или нет; файлы можно бросать прямо в неё
- Можно спрятать панель задач Windows — она вернётся при выходе из DockDesk

### Исправлено
- Это первая версия.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
