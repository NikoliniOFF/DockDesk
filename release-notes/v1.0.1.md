## 👀 DockDesk для Windows 1.0.1

**Скачать:** `DockDesk-1.0.1-win64.zip` ниже (или постоянная ссылка `DockDesk-win64.zip`). Распакуйте и запустите `DockDesk.exe`.

### Что нового
- Новый значок DockDesk — в общем стиле программ Nikolini: монитор с доком на экране
- В «О программе» — все программы Nikolini: HubDesk, WinterDesk, PeekDesk, SnapDesk, SpotDesk и IslandDesk
- Список программ обновляется сам, когда вы открываете «О программе», — новые программы появятся без новой версии DockDesk

### Исправлено
- Проверка обновлений больше не упирается в лимит GitHub (ошибка 403): версия определяется без api.github.com, а при временной ошибке сети или лимите программа молча повторит попытку при следующей проверке
- SnapDesk в «О программе» открывает свой сайт, а не общую страницу автора на GitHub

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
